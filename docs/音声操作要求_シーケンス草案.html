音声操作の利用例

草案・未確定：実装済みの動作ではありません。草案本文

THE SESSION TOOLSが操作可能な状態にある場合の例です。管理画面は開いていません。矢印はやり取りの方向を示します。

1. 管理画面を開かず「テンポを少し上げて」と話す

利用者
音声アシスタント
THE SESSION TOOLS
起動時に対象の状態を確認 →
← 操作可能
音声認識の利用を開始
「みらい、テンポを少し上げて」 →
音声を認識し、対象と操作を決定
BPM +5を要求 →
操作可能か確認し、BPMを5上げる
← 成功・変更後のBPM
応答を受け取り、要求の結果を管理

管理画面が表示できないページでも、アシスタントの実行基盤が動作していれば要求を受け付ける設計です。対象のタブが操作可能かは別に確認します。表示不能ページでの継続動作は未検証です。

2. BPM変更中に対象拡張が再読み込みされる

利用者
音声アシスタント
THE SESSION TOOLS
起動時に対象の状態を確認 →
← 操作可能
音声認識の利用を開始
「みらい、テンポを少し上げて」 →
BPM +5を要求 →
要求を記録し、BPMの変更を処理
結果の記録前に拡張が再読み込みされる
応答を受け取れず、結果不明
再起動後、要求記録は失われる
同じ要求IDの状態を照会 →
← 記録なし（実行の有無は不明）
結果不明として扱い、自動再実行しない

再読み込み後に要求記録が失われた場合の例です。管理側が要求IDを保持できる場合の照会を示します。両側が同時に停止した場合の復旧方法は未確定です。

管理画面のイベント表示は初期段階では保存しません。音声受付や要求状態の管理は管理画面と独立させます。
