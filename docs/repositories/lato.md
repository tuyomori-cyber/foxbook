# lato 横断管理

## このリポジトリの責務

- 設定したローカルルート配下のMarkdown文書を、タッチ操作で探索・閲覧する読み取り専用Firefox拡張を提供する。
- 文書または親ディレクトリのLinux絶対パス、およびファイル名をコピーできるようにする。
- ローカルファイルの列挙・読取はNative Messaging Hostの固定操作に限定する。Host側で端末ごとの単一ルートを固定し、拡張は相対パスだけを送ることで、ルート外アクセスや任意コマンド実行を許可しない。

## 参加インターフェース

- 現時点で、他リポジトリとの共有インターフェースはない。Native Messaging Hostとの内部プロトコルは、実装着手時に必要なら契約として登録する。

## 変更時の影響確認

- ローカル読取の権限境界、パス正規化、シンボリックリンクの扱いを変える場合は、安全性を実機で確認する。MVPではHost設定のルートを拡張から変更できない。
- 他リポジトリとルート設定・パス受け渡し・表示連携を共有する場合は、先にインターフェース契約を追加する。
